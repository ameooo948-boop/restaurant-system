# Checkpoint 03 — Test Matrix

| السيناريو | السلوك المتوقع |
|---|---|
| موظف لديه `menu.view` | يستطيع عرض التصنيفات والمنتجات والإضافات بفرعه |
| موظف ليس لديه `menu.view` | 403 |
| مدير فرع فقط | لا يحصل على `menu.catalog.manage` ولا يستطيع تعديل كتالوج المطعم المشترك |
| مالك المطعم | يستطيع تعديل الكتالوج المشترك من فرع مسند إليه |
| Category من مطعم آخر | رفض 422 عند ربطها بمنتج |
| Product Variant | سعر أساسي وSKU وVariant افتراضي واحد |
| Branch Product Setting | يمكن تجاوز السعر أو تعطيل توفر المنتج بفرع محدد |
| Modifier Group | يفرض حدود اختيار منطقية |
| Modifier Option | فرق سعر أساسي مع تجاوز اختياري لكل فرع |
| موظف من فرع آخر | 403 قبل الوصول إلى Controller |
| حذف Category مستخدم | رفض الأرشفة حتى يتم نقل المنتجات/التصنيفات الفرعية |

تشغيل الحزمة: `php artisan test --filter=MenuManagementTest`، ثم اختبارات Checkpoint 01 و02 و`npm run build`.
